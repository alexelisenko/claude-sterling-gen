## Plan

- [x] **Phase 0 — Harness.** Parametric CAD pipeline: params -> parts -> renders, interactive animated viewer, dimensioned A3 drawings, STEP/STL/DXF. Proven on 2 demo parts.
- [ ] **Phase 1 — Thermo sizing.** Schmidt analysis + West/Beale cross-check. Outputs: bore, stroke, frequency, charge pressure, mean/swing pressures, heater & cooler dimensions, regenerator envelope. Decide working gas strategy (air first, helium capable).
- [ ] **Phase 2 — Architecture layout.** Opposed free-piston pair sharing central combustion zone (balance). Decide: displacer drive, piston suspension (flexures vs close-clearance), linear alternator topology (moving magnet likely), bounce space. Full-engine envelope model in the viewer.

- [ ] **Phase 5 — Fabrication package.** Numbered drawing set (PDF bundle), STEP set, BOM with stock sizes, fastener list, make-vs-buy per part.
